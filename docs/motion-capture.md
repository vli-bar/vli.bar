# PICO のモーション録画

WebXR から頭部と左右コントローラーの位置・回転を取得します。カメラ映像・音声・部屋の画像は記録しません。PICO の全身トラッキングやモーショントラッカー専用 API を使用していないため、全身の実測データではありません。

録画には HTTPS の WebXR 対応ブラウザ、追跡可能な HMD、左右コントローラーが必要です。AR の利用可否と、PICO Browser から各トラッキング情報が得られるかは実機で確認してください。WebXR の標準 API は [W3C WebXR Device API](https://www.w3.org/TR/webxr/) を参照しています。

## 記録形式

JSON の `format` は `vli.motion-capture`、`version` は `1`。単位はメートル、右手系・Y 上向きです。原点は録画開始後に最初に追跡できた頭部位置、正面はその時の頭の水平方向です。元の参照空間と原点変換は `referenceSpace` と `origin` に残します。

- `fps`: 記録頻度の上限。通常 30 Hz。
- `duration`: 最終フレームの時刻。最長 180 秒。
- `initialHeadHeight`: floor 空間の場合の最初の頭部高さ。それ以外は `null`。
- `frames`: 単調増加する秒単位の `t`、`visibility`、`head`・`left`・`right`。
- 各トラック: `position: [x,y,z]`、`quaternion: [x,y,z,w]`、`emulatedPosition`。追跡できない時は `null`。

最初の有効な頭部フレームを時刻 0 とします。非表示・フォーカスを失ったフレームには位置や回転を入れません。ブラウザがフレームを停止して長い空白が生じた場合、再生はその間を補間しません。

アップロード操作は端末上のファイル取り込みです。サーバーへ送信しません。取り込みは 12 MB・180 秒・最大 60 Hz の上限、数値、時刻順序、クォータニオン、フォーマットバージョンを検証します。

## アバター再生の範囲

頭の向きと移動を反映し、腕はコントローラー位置を目標にした 2 ボーン IK で推定します。胴体・脚・ひじの曲がる向きも推定です。指・足・ひじそのものを計測したデータはなく、コントローラーの握り方に依存する手首回転も現状では VRM に反映しません。生データにはコントローラーの回転を保存しており、後のリターゲット処理に利用できます。

## 開発用検証

`tests/fixtures/capture-sample.json` はインポート・再生 UI を検証するための合成データです。実際の PICO 録画ではありません。2 秒・61 フレームの頭の移動と左腕の動きが含まれます。

自動テストは座標校正、取り込み拒否条件、欠落トラッキング、補間、録画上限と保持、腕の IK を検証します。PICO 実機の入力やダウンロード動作を保証するものではありません。
